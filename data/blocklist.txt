# Default content blocklist for Moniker (the "slur / offensive" filter).
#
# Purpose: keep the SERVER NAME and rename cards from being set to hate speech.
# This is intentionally scoped to genuine slurs and hate terms, NOT broad
# profanity — edgy-but-harmless quotes are the point of the bot, so "damn",
# "sex", etc. are deliberately absent. Servers can add their own terms with
# /config blocklist add.
#
# One term per line, lowercase. Blank lines and #-comments are ignored.
# Matching is whole-word and case-insensitive (so "assassin" is NOT caught by
# a substring). Leetspeak / spaced-out evasions are not exhaustively covered —
# a blocklist is a blunt instrument that catches the obvious, not everything.
#
